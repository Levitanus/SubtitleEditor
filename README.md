# Subtitle Editor

Приложение на Rust + egui для редактирования субтитров YouTube.

## Возможности
- Импорт/экспорт файлов: txt, sbv, seproj (JSON)
- Редактирование строк: разделение, объединение
- Diff view для сравнения транскрипта и субтитров
- Экспорт в sbv с новыми тайм-кодами

## Запуск
```bash
cargo run
```

## Зависимости
- egui
- eframe
- serde
- serde_json
